# Changelog

## [28.0.0.0] - Unreleased

- Fix the Goal.Set Read-role visibility test with a test-only Execute permission set (98037). It reaches `IsEnabled()` under restrictive permissions and explicitly asserts that the write marker remains denied before checking that the type is hidden.

- Add `Sustainability.Category.Set`: atomic, idempotent category and subcategory maintenance through Microsoft validation, with Full-only access and bilingual contract help. Enum extension, enum value, implementation codeunit and empty permission capability table use 70009211. Dispatcher tests use 98030-98031.
- Use Foundation `RecordNotFound` and `PreconditionFailed` for preview refusals, with the requested template/batch in missing-batch diagnostics. Public help regression coverage validates the complete contract in English and Icelandic (Architect clarification of #9 AC04).

- Add `Sustainability.Journal.PreviewPost` (enum extension/value, capability table and implementation 70009215; rollback adapter codeunit 70009227), with translated contracts, input refusals and preview totals. Posting uses temporary journal lines and rolls back after the standard approval check, before deletion; Read users need no journal-delete permission. Number-series changes roll back. Dispatcher coverage is in test codeunit 98050 with permission fixture 98051.

- Fixed Full-role journal creation with open approvals by granting read access to User Setup. Permission tests now seed unrelated open approvals for another approver and cover native approval checks plus rollback without losing existing journal lines (#7).

- Added `Sustainability.Journal.Create`: atomic journal creation with native manual/formula validation, Full-only permissions, bilingual help and named refusals (#7). Added enum extension/value, implementation codeunit and capability table 70009213; test codeunits 98040-98041, fixture codeunit 98042 and test execution permission set 98043. No ledger posting.
- Added `Sustainability.Journal.Check` (#8): enum extension/value, implementation and capability table 70009214, rollback runner codeunit 70009228. Uses the standard batch validator, returns all line errors, treats empty batches as not ready and commits no journal or ledger changes. Includes Foundation Read/Full capability grants, bilingual help, and dispatcher/rollback tests 98045–98047.
- Added `Sustainability.AccountBalance.Get`: native account net change, balance and totals with date, global-dimension and responsibility-center filters; stored CO2e is summed without recalculating emission factors. Added enum extension/value and implementation codeunit 70009208, Read-role grants, bilingual contracts and dispatcher tests in codeunit 98015.
- `Sustainability.Scorecard.Get` (enum extension 70009209, codeunit 70009209) reads a sustainability scorecard and its goals, with baseline, current, target and progress. Read only: it does not post.
- Test codeunit 98021 asserts the amended AC-P boundary: Foundation Read and Full (70009205, 70009204) grant execution only. Native scorecard, goal and ledger reads come from `BIFROST SustRead ori` (70009203) assigned alongside. Without those reads the type is hidden and the call returns PermissionDenied. Test permission set 98023 holds the message-argument rows that fixture needs.
- Shared visibility check `Sust Configured ori` (codeunit 70009206, #1, Gunnar's decision D5): a company counts as configured when Sustainability Setup has an Emission Unit of Measure Code or at least one Sustainability Account exists; no read permission means not configured, never an error. `BIFROST Sustain ori` (70009201) grants the registration, the visibility check and read on Sustainability Setup (6217) and Sustainability Account (6210). `BIFROST SustRead ori` (70009203) adds execute on the account-balance reader and the scorecard reader, and read on the sustainability account, scorecard, goal and ledger entry. `BIFROST SustFull ori` (70009202) includes the read set. The Foundation Full and Read role extensions (70009204-70009205) grant this app's own codeunits directly instead of including the Sustainability sets, so no Microsoft table data is added through a permission set extension (AppSourceCop AS0110/AS0112).
